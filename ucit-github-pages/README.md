# UCIT - Publication sur GitHub Pages

1. Creer un depot public nomme ucit-site sur GitHub.
2. Decompresser cette archive.
3. Dans le depot, utiliser Add file > Upload files et deposer tous les fichiers et le dossier assets a la racine. Le fichier index.html doit etre directement a la racine du depot. Valider avec Commit changes.
4. Ouvrir Settings > Pages > Build and deployment. Choisir Deploy from a branch, puis la branche main et le dossier /(root). Cliquer sur Save.
5. Attendre la publication, puis ouvrir Visit site dans Settings > Pages.

Adresse habituelle : https://VOTRE-COMPTE.github.io/ucit-site/

Ce site est statique et autonome. Il ne necessite pas de connexion ChatGPT. Les formulaires preparent des messages a envoyer via e-mail ou WhatsApp. Le portail etudiant reste a connecter a un systeme academique.

Les informations academiques, le logo et les photos officiels restent a valider par UCIT. Le visuel fourni est une illustration generee par IA, signalee sur le site.

Documentation : https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
